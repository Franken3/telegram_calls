# 📞 Telegram Caller

**Звонки через Telegram из терминала для мгновенных уведомлений**

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://python.org)
[![Telethon](https://img.shields.io/badge/Telethon-1.34+-green.svg)](https://github.com/LonamiWebs/Telethon)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 🎯 Зачем это нужно?

Когда важные события требуют **мгновенной реакции** — сообщения легко пропустить. Звонок в Telegram привлекает внимание моментально.

**Примеры использования:**
- 🚀 Уведомление о листингах криптовалют
- 📊 Алерты мониторинга серверов
- 🔔 Срочные уведомления для команды
- ⏰ Напоминания, которые нельзя игнорировать

---

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📞 **Звонок по username** | `@durov` — позвонить пользователю |
| 🔢 **Звонок по ID** | `123456789` — если username неизвестен |
| 👥 **Массовые звонки** | `@user1 @user2 @user3` — несколько пользователей |
| ⏱️ **Настройка длительности** | От 1 до 60 секунд |
| 💬 **Сообщение перед звонком** | Отправка текста перед вызовом |
| 💾 **Автосохранение сессии** | Авторизация один раз |

## 🚀 Быстрый старт

### 1. Установка

```bash
git clone https://github.com/your-username/telegram-caller.git
cd telegram-caller
pip install telethon
```

### 2. Получение API ключей

1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Войдите в свой аккаунт
3. Перейдите в **API development tools**
4. Создайте приложение и скопируйте **API ID** и **API Hash**

### 3. Запуск

```bash
python telegram_calls.py
```

При первом запуске введите:
- API ID и API Hash
- Номер телефона
- Код подтверждения из Telegram

## 📖 Использование

### Основные команды

```
📞 > @username              Позвонить пользователю
📞 > 123456789              Позвонить по ID
📞 > @user1 @user2          Позвонить нескольким
```

### Настройки

```
📞 > /time 10               Установить длительность 10 сек
📞 > /msg Важно!            Сообщение перед звонком
📞 > /msg off               Отключить сообщение
📞 > /status                Текущие настройки
📞 > /me                    Информация об аккаунте
📞 > /help                  Справка
📞 > /quit                  Выход
```

### Пример сессии

```
╔═══════════════════════════════════════════════════════════════╗

✅ Подключено как: @my_account (Иван)

📞 > /time 5
⏱️  Длительность звонка: 5.0 сек

📞 > /msg 🚨 Срочное уведомление!
💬 Сообщение перед звонком: "🚨 Срочное уведомление!"

📞 > @trader1 @trader2 @trader3

📞 Звоню 3 пользователям...

   📞 Звоню @trader1... ✅ (5.0с)
```

## ⚙️ Конфигурация

### Файлы

| Файл | Описание |
|------|----------|
| `caller_config.txt` | API ID и API Hash |
| `caller_session.session` | Сессия Telegram |

### Переменные в коде

```python
SESSION_FILE = "caller_session"      # Имя файла сессии
DEFAULT_RING_DURATION = 5.0          # Длительность по умолчанию
CONFIG_FILE = "caller_config.txt"    # Файл конфигурации
```

## 🔒 Безопасность

- ✅ Credentials хранятся локально

## 🐛 Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `🔒 Приватность` | Пользователь запретил звонки | Попросите изменить настройки |
| `❓ Не найден` | Неверный username/ID | Проверьте правильность |
| `⏳ Flood wait` | Слишком много запросов | Подождите указанное время |
| `PHONE_CODE_INVALID` | Неверный код | Запросите код повторно |
